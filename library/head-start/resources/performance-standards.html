From Standards to Practice

Use the standards as a reference point for understanding program expectations and considering how those expectations appear in daily classroom practice.

📋 Review

Identify the standard or program expectation relevant to the work you are planning or documenting.

👀 Observe

Gather meaningful evidence of children's experiences, interactions, learning, and development.

📝 Document

Record observations and classroom evidence clearly so it can inform planning and reflection.

🌱 Reflect

Consider what the evidence suggests about classroom practice and possible next steps.
