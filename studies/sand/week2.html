🪣 Week 2: Scoop, Pour & Measure

WEEK TWO

Measure • Compare • Experiment

🪣 Scoop and Pour

Use cups, scoops, and containers to explore how much sand each holds.

⚖️ Compare Amounts

Predict which container holds more or less, then test the prediction.

🔢 Count Scoops

Count how many scoops fill different containers and record the results.

🧰 Tool Investigation

Compare funnels, sieves, spoons, cups, and other tools to see how each changes the experience.
